# Lee Ann Holdings

Local website for Lee Ann Holdings. Pages, copy, images, and styles are in this folder so you can run and change the site on your machine.

## Run locally

```bash
cd grand-vista-holdings
npm install
npm run dev
```

Then open http://localhost:5173

## Scripts

- `npm run dev` — Vite development server
- `npm run build` — production build
- `npm run preview` — preview the production build

## Project layout

- `src/pages` — Home, About, Divisions, Contact, and each division page
- `src/data/divisions.ts` — division copy and images
- `src/components` — shared header/footer and division layout
- `src/assets` — hero and division photos
